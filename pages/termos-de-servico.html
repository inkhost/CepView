2. O que o CepView faz

O CepView é uma ferramenta gratuita de consulta de endereços brasileiros, que permite buscar um endereço a partir de um CEP e, de forma inversa, encontrar o CEP a partir de uma rua, cidade e estado. Os dados exibidos são obtidos de uma API pública de terceiros (ViaCEP), com base nas informações oficiais dos Correios.
